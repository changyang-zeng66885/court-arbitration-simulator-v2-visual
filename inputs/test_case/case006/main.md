# 北京尚业影视文化传媒有限公司 诉 UCFTI, Inc. 及 陈作宏 电影发行权投资合同争议仲裁案

## 案件背景
申请人北京尚业影视文化传媒有限公司（以下简称“申请人”）与被申请人一 UCFTI, Inc.、被申请人二陈作宏（Zuohong Chen）于某年签订了一份《电影发行权投资合同》（Film Distribution Right Investment Contract）。根据该合同，申请人投入资金，被申请人负责相关电影的发行并按照约定向申请人支付投资回报。后因被申请人未完全履行付款义务，双方产生争议。合同中载有仲裁条款，约定因本合同引起的或与本合同有关的任何争议，应提交北京仲裁委员会（北京国际仲裁院）按照该会届时有效的仲裁规则进行仲裁。申请人遂于2019年向北京仲裁委员会/北京国际仲裁院提起仲裁。本案适用该会2019年《北京仲裁委员会仲裁规则》第八章“国际商事仲裁”的规定。仲裁地为北京，适用法律为中华人民共和国法律。以下为正式开庭前双方所准备及提交的材料。
