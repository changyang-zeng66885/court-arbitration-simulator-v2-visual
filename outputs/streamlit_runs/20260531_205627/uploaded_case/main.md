# SG Commodities v. FGHK

## 案件背景

本案涉及一份于2015年12月签订的铜阴极购销合同（下称“购销合同”），买方为 **新加坡商品集团有限公司**（Singapore Commodities Group Co., Pte. Ltd.，下称“申请人”），卖方为 **方正集团（香港）有限公司**（Founder Group (Hong Kong) Ltd.，下称“被申请人”）。购销合同包含多层级争议解决条款，约定当事人应首先通过友好协商解决争议，协商不成的，应将争议提交中国国际经济贸易仲裁委员会（CIETAC）仲裁，合同的准据法为中华人民共和国法律。

被申请人于2021年7月19日由香港法院颁令清盘，其清盘人审查公司账簿后发现一笔由申请人结欠的债务，本息合计 14,117,585.50 美元（下称“系争债务”）。该笔债务最初体现于由申请人审计师向被申请人发出的三份审计确认函中，三份函件所载日期为2018年至2022年，但第一份函件实际发出时间应为2019年。被申请人于2022年2月18日向申请人发出法定求偿书，要求支付系争债务，后同意将答复期限延长至2022年3月21日。

申请人未支付系争债务，并于2022年4月12日向贸仲申请仲裁，请求仲裁庭作出宣告性裁决，确认其并不负担系争债务。申请人主张，购销合同自始无效，因双方在签订合同时并无真实买卖铜阴极的意图，该合同仅为会计及记账目的而订立；同时，被申请人从未向申请人交付任何铜阴极。被申请人则抗辩称合同有效，且系争债务真实存在。

被申请人虽在仲裁程序中提出管辖权异议，但未就系争债务提出反请求。随后，被申请人于2022年5月27日向新加坡法院提出对申请人的清盘申请，由此引发后续一系列法院程序。然而，本模拟案例仅限于仲裁程序开庭前所形成的材料，不涉及任何法院程序或仲裁庭最终裁决。

### 材料2：仲裁申请书

（注：因仲裁通知已包含基本请求，本申请书为补充详尽论述及支持性证据。）

**申请人：新加坡商品集团有限公司**  
**被申请人：方正集团（香港）有限公司**

**一、仲裁基础**

1.1 申请人与被申请人于2015年12月签署《铜阴极购销合同》（附件C1），合同名称及条款看似为真实的货物买卖。然而，合同双方在整个交易过程中均无实际买卖铜阴极的意图，购销合同系为满足集团内部记账、融资或账务处理需求而制作的形式文件。

1.2 根据《中华人民共和国民法典》第146条，“行为人与相对人以虚假的意思表示实施的民事法律行为无效。”申请人与被申请人之间不存在真实的买卖铜阴极的意思表示，故购销合同应属无效。

1.3 即使仲裁庭认为合同有效，申请人也明确主张：被申请人从未按合同约定向申请人交付任何铜阴极货物，因此申请人的付款义务从未产生，系争债务根本不存在。

**二、事实陈述**

2.1 申请人与被申请人在签署购销合同时，同属由北京大学方正集团有限公司（PUFG）最终控制的公司集团。集团内部经常出于统一财务管理、融资便利或会计目的，安排关联公司之间签署形式上的交易合同，而不伴有真实的货物交付或服务提供。

2.2 购销合同签署后，被申请人从未向申请人交付铜阴极。申请人亦未收到任何装船提单、运单、仓单、质检证书或保险单等履行交货义务通常应具备的单证。

2.3 申请人审计师在2019年至2022年间曾向被申请人发出审计确认函（附件C2），该等函件系为审计目的按集团统一口径发出，所反映的“应付账款”数据来源于集团合并报表层面的会计记录，并不代表申请人独立承认该债务的存在。根据中国相关法律规定及会计审计准则，审计确认函不能作为证明债权债务关系真实存在的直接证据。

2.4 被申请人于2022年2月18日向申请人发出法定求偿书，要求支付14,117,585.50美元。申请人始终对该债务持有异议，并在规定的期限内提起本仲裁。

**三、法律主张**

3.1 购销合同因缺乏真实意思表示而无效（《民法典》第146条）。

3.2 即便合同有效，被申请人未证明其已履行交货义务，故申请人的付款条件未成就，系争债务不发生。

3.3 被申请人据以主张债务的审计确认函不具有确认债权债务的法律效力，不能替代买卖合同项下交付货物与付款请求权的实质审查。

**四、仲裁请求**

恳请仲裁庭裁决：
(a) 宣告申请人对被申请人并不负担任何金额的债务，尤其是14,117,585.50美元的系争债务；
(b) 宣告购销合同因虚假意思表示而无效；
(c) 被申请人承担本仲裁的全部费用及申请人的合理律师费与开支。

#### 附件C6：中国法律专家报告（申请人方）

**由：中伦律师事务所（Zhong Lun Law Firm）**  
**日期：2022年4月10日**

**出具人：**[专家姓名]（中国执业律师，擅长合同法、证据法）

**委托事项：** 就审计确认函在中国法下的证明力提供专家意见。

**意见摘要：**

1. 根据《中国注册会计师审计准则》及相关司法实践，审计确认函是注册会计师为获取审计证据而向第三方发出的书面询证函。其作用是核实被审计单位账簿记载的准确性，本身并非对债权债务关系的确认。最高人民法院在多个判例中均指出，审计确认函“不能作为直接证据用于认定债权债务关系”，其证明力弱于欠条、对账单等直接债权凭证。

2. 审计确认函所记载的金额来源于被审计单位的内部会计记录，而会计记录可能因各种原因（包括集团内部做账、税收筹划、虚构交易等）未能反映真实的交易情况。因此，仅凭审计确认函不能证明债权债务关系的真实存在。

3. 在本案中，被申请人仅凭三份审计确认函主张债权，但未提供任何履行交货义务的客观证据（如提单、运单、质检单等）。依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第90条，被申请人未能就其主张的合同履行事实提供充分证据，应当承担举证不利的后果。

综上，从中国法律角度分析，审计确认函不足以单独或共同证明系争债务的存在。
