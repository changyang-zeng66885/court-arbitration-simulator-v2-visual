# 申请方庭前总顾问建议

## 1. 我方律师提问策略

**核心思路**：以《民法典》第146条“虚假意思表示无效”为主轴，同时坚持“被申请人从未交付铜阴极”的独立抗辩。庭审中应通过精准的封闭式问题压缩对方证人的解释空间，并在盘问后立即向仲裁庭总结逻辑矛盾，主动申请程序性不利推定以固化优势。

### 1.1 压缩对方证人解释空间的问题设计技巧
- **首问锁定事实缺失**：直接要求对方出示具体文件（提单、运单、内部调拨单、调档函记录等），迫使对方承认无法提供或者仅能提供模糊陈述。例如：“清盘人先生，请向仲裁庭出示任何一份显示铜阴极所有权从被申请人转移至申请人的内部调拨单的具体编号、日期和发出公司名称。”
- **二问追索调查过程**：若对方以“正在搜寻”“保密”回避，立即追问其调查路径：“您向哪些关联公司发出了调档函？请提供发送记录。若无法提供，是否意味着您声称的‘关联物流安排’纯属推测？”——这一追问已在第5轮、第6轮训练中成功迫使清盘人承认无法当场提供细节。
- **三问总结并申请不利推定**：当对方承认无法提供关键证据后，立即向仲裁庭做简短口头总结：“贵庭已注意到，清盘人承认无法提供内部调拨单的任何具体信息，也无法提供调档函发送记录，其关于交付已履行的主张缺乏证据支持。”随即申请：“请求仲裁庭命令被申请人在7日内提交内部调拨单的脱敏副本及调档函发送记录；若逾期未能提交，请求仲裁庭作出该等文件不存在或不利于被申请人的推定。”

### 1.2 针对对方证人逻辑矛盾的追击路径
- **对清盘人**：逐层揭露其“关联物流安排”的猜测性。第1轮训练中清盘人两次承认无任何运输单据和内部记录，但律师未立即总结。终版策略要求盘问后立即总结，例如：“清盘人先生，您已两次承认——无提单、无运单、无内部调拨单、无邮件记录；您断言交付已履行，但这仅是猜测，对吗？”然后不等其辩护，转向仲裁庭总结。
- **对被申请人律师**：当对方攻击我方证人“未告知审计师”时，我方律师应在再交叉盘问中要求对方提供确认余额请求函的发出记录、内部审批单，若无法提供则请求仲裁庭对该函的可信度作出不利认定。该策略已在第2轮复盘中明确。

### 1.3 善用程序规则抵抗管辖权异议
- 被申请人在仲裁通知答复中提出了管辖权异议（主张合同无效则仲裁条款无效），我方应坚持仲裁条款独立性原则。可当场援引贸仲规则和司法案例：
> [公开案例数据库（RAG）, case:case007:0008] 原文：'2023年4月28日，鸿坤伟业公司、赵彬向贸仲提出仲裁管辖异议申请书。2023年5月19日，贸仲作出（2023）中国贸仲京字第048121号仲裁通知，认为“被申请人（鸿坤伟业公司、赵彬）提出的关于本案管辖权问题需要仲裁庭就相关问题进行审理后才能作出决定，因此根据《仲裁规则》第六条（五）款"对仲裁协议及/或仲裁案件管辖权提出异议不影响仲裁程序的继续进行"的规定，决定本案程序继续进行，管辖权问题将在仲裁庭对本案进行实体审理后再予以决定”。'
> [法律条文知识库（RAG）, law:北京国际仲裁法院-国际仲裁规则:0014] 原文：'（三）当事人提出管辖权异议不影响仲裁程序的进行。'
- 据此强调：仲裁程序不应因管辖权异议而中止，仲裁庭应在实体审理中一并决定管辖权问题。

### 1.4 盘问后的即时总结与程序行动清单
- **盘问后立即总结**：在每段交叉盘问结束后，用30秒向仲裁庭概括矛盾点，固化盘问成果。例如：“清盘人已承认无任何文件支持交付主张，其全部抗辩仅依赖会计数字；而这些会计数字六年不变，恰恰反证无真实交易——我方的中国法律专家报告也指出审计确认函不能作为债务承认。”
- **申请不利推定**：若对方以“保密”“整理中”为由拒不提交文件，立即申请仲裁庭作出期限命令和不利推定。该策略在第5轮、第6轮训练中已有明确经验。

## 2. 我方证人回答策略

### 2.1 核心回答口径
始终围绕“合同系虚假意思表示，无真实交易，账务记录仅为集团会计安排”的核心叙事，并主动引入“固定金额六年不变恰恰反证无真实交易”的逻辑链，防止被动防守。具体要点：
- **财务报表连续列示应付账款**：承认事实，但立即转入“该数字源于集团合并报表指令，六年不变反证无真实交易”。
- **审计确认函**：承认收到但未提出异议，但强调“函件仅核实数字一致性，不涉及交易实质；当时无独立法律审查，不认为需要提出异议”。
- **确认余额请求函**：财务总监坚持“对该函无印象，印章可疑”，并主动要求对方提供发送记录。
- **为何不冲销**：解释冲销会破坏集团会计一致性，且该金额六年不变反证其仅为账面数字，非真实债务。

### 2.2 最小必要承认原则
当被明确锁定时，仅承认确凿事实，并立即附加己方合理解释，避免单独让步。例如：
- **被问“是否告知审计师合同虚假”**：首先主动陈述背景——“该应付账款是应集团会计政策记录的账面数字；审计确认函仅为核实数字；六年不变恰好反证无真实交易；当时我司无独立法律部门参与该账务处理，我不认为该函涉及债务的法律承认。”然后承认“没有特别向审计师说明”，但立即归结为“因此未主动提出法律定性问题，这并不违反诚信义务”。（参见第6轮训练中财务总监的回答，该回答成功避免了直接承认违规。）
- **被问“是否符合诚信义务”**：必须完整表述四个要素：审计确认函性质+集团会计政策要求+金额六年不变反证+当时无独立法律审查。具体话术：“当时我司无独立法律部门参与该账务处理，我基于对审计函目的的理解，不认为该函涉及债务的法律承认，因此未主动提出法律定性问题，这并不违反诚信义务。”

### 2.3 防御性陈述顺序
- **先发制人引入反证逻辑**：在对方尚未追问前，主动在回答中嵌入“固定金额六年不变恰恰说明无真实交易”。例如第5轮财务总监在回答“是否告知审计师”时，先引入该逻辑再承认未说明，有效削弱了对方攻击。
- **引用专家报告时说明来源**：应说“这是我们聘请的独立中国法律专家出具的报告，其意见已提交仲裁庭，与最高人民法院司法实践一致”，避免被攻击为单方偏见。

### 2.4 不要承认的事项
- 不要承认确认余额请求函的印章为真实印章（财务总监已表示怀疑）。
- 不要承认审计确认函上的余额具有债务确认的法律效力。
- 不要承认申请人曾基于合同向被申请人作出任何付款承诺。
- 不要承认在会计处理中曾对系争债务的实质交易进行过独立审查。

## 3. 需要重点关注的风险点

### 3.1 律师风险
| 风险 | 说明 | 应对 |
|------|------|------|
| 盘问后未即时总结 | 第1轮、第2轮、第5轮训练中多次错失固化盘问成果的机会 | 每段盘问后立即向仲裁庭做30秒口头总结 |
| 未申请不利推定 | 当对方以“保密”“整理中”回避时，未主动要求仲裁庭命令或推定 | 终版策略已加入：当场申请仲裁庭命令限期提交，逾期则请求不利推定 |
| 对管辖权异议纠缠过多 | 若花时间辩论管辖权，将偏离实体焦点 | 坚持引用贸仲规则和案例（case007:0008）说明不影响程序进行，然后迅速回归实体 |
| 未要求对方提供确认余额请求函发送记录 | 对方可能利用该函作为表面证据 | 在再交叉盘问中要求对方提供发出记录、审批单，无法提供则请求仲裁庭认定不可靠 |

### 3.2 证人风险
| 风险 | 说明 | 应对 |
|------|------|------|
| 仅以“集团会计政策”为挡箭牌而无书面证据 | 第5轮训练中财务总监承认未冲销时仅依赖口头指令解释，易被质疑 | 提前准备书面备注或邮件副本（如有）；若无，则先发制人说明“集团指令为内部口头传达，已过去多年无法提供书面记录，但金额六年不变本身就是反证” |
| 回答“是否告知审计师”时顺序不当 | 第6轮训练中财务总监虽引入反证逻辑，但若先承认未告知再解释，可能让对方先获得不利承认 | 应按“先背景解释，再承认事实”的顺序：先讲审计函性质、六年不变反证，后承认未特别说明，并强调不认为需要 |
| 对“诚信义务”回答不完整 | 第6轮训练中财务总监未提及“无独立法律审查”，导致回答未充分回应质疑 | 必须完整表述四个要素（见2.2） |
| 对确认余额请求函印章问题语气犹豫 | 若被连续追问，可能动摇证词可信度 | 坚持“无印象、印章可疑”，并主动要求对方提供原始发出记录 |
| 财务总监对集团会计政策细节表述不清 | 若被追问具体时间、指令发出人，可能陷入被动 | 提前梳理一份关于“集团2015年财务指令”的书面备忘（口头传达记录），并训练在回答中强调“该类指示通常口头下达，集团惯例如此” |

## 4. 训练中的具体例子

以下各例均来自多轮独立庭前训练，用于说明哪些失误需要避免、哪些攻击点可以保留。请注意：这些训练中的回答并非同一场真实庭审的连续既成事实。

### 4.1 需要避免的失误

**例1：未及时总结盘问成果（第1轮）**
- 背景：申请方律师成功迫使清盘人两次承认无法提供任何运输单据或内部记录。
- 失误：律师在盘问结束后没有立即向仲裁庭总结逻辑矛盾（如“清盘人承认无任何文件支持交付主张”），导致盘问成果未被即时固化。
- 改进措施：终版策略已要求在每段盘问后立即做简短口头总结。

**例2：证人引用专家报告未说明来源（第2轮）**
- 背景：财务总监在回答审计确认函证明力时直接引用中国法律专家报告。
- 失误：未提前说明“这是我方单方委托的专家报告”，可能被对方后续攻击报告的客观性。
- 改进措施：应说“这是我们聘请的独立中国法律专家出具的报告，其意见与最高人民法院司法实践一致”。

**例3：证人回答“诚信义务”时未提及无独立法律审查（第6轮）**
- 背景：被申请人律师质问财务总监“未告知审计师是否符合诚信义务”。
- 失误：财务总监虽解释了审计函性质，但未加上“当时我司无独立法律部门参与该账务处理”这一关键理由，导致回答缺少完整防御。
- 改进措施：终版策略要求必须完整表述“审计确认函性质+集团会计政策要求+金额六年不变反证+当时无独立法律审查”。

### 4.2 可以保留的攻击点

**例4：持续迫使清盘人无法提供具体文件细节（第5轮、第6轮）**
- 背景：申请方律师连续追问清盘人“内部调拨单的具体编号、日期、发出公司名称”，清盘人均以“保密”“整理中”回避。
- 保留价值：该攻击成功暴露了被申请人关键证据的缺失，仲裁庭会注意到其无法当场提交。庭审中应进一步申请不利推定。

**例5：迫使清盘人承认搜寻记录不完整（第2轮、第3轮）**
- 背景：清盘人承认无法提供调档函发送记录和具体实体名单。
- 保留价值：该承认直接削弱了其“关联物流安排”主张的可信度。庭审中应以此为跳板，要求仲裁庭命令被申请人限期提交。

**例6：财务总监主动引入“固定金额六年不变反证无真实交易”逻辑（第5轮）**
- 背景：在被问到“是否告知审计师”时，财务总监先发制人引入该逻辑，成功将未告知行为合理化为对账面数字性质的合理认知。
- 保留价值：该口径已经在第5轮、第6轮训练中验证有效，应作为标准回答模板。

## 5. 庭前行动清单

### 5.1 律师准备事项
- [ ] **准备盘问提纲**：针对清盘人，设计三连问闭环——要求具体文件→追索调查路径→申请不利推定。针对被申请人律师，准备再交叉盘问中要求提供确认余额请求函的发出记录。
- [ ] **准备即时总结话术**：编写30秒口头总结模板，例如“贵庭已注意到，清盘人承认无任何记录支持交付，其主张纯属猜测；我方请求仲裁庭命令被申请人在7日内提交内部调拨单脱敏副本，否则请求不利推定。”
- [ ] **准备管辖权异议应对**：熟记贸仲规则第六条和案例case007:0008，可在口头陈述中引用。
- [ ] **准备申请不利推定的程序性请求**：如对方以保密为由拒不提交，立即请求仲裁庭记录并作出不利推定。

### 5.2 证人准备事项
- [ ] **模拟交叉盘问**：至少进行两轮模拟，重点训练对“是否告知审计师”“为何不冲销”“是否符合诚信义务”三个高风险问题的完整回答顺序。
- [ ] **确认“固定金额反证”逻辑链的熟练度**：财务总监必须能自然地在多个回答中嵌入“六年不变恰恰反证无真实交易”这一论证。
- [ ] **准备书面备忘**：整理一份关于“集团2015年财务指令”的书面描述（时间、来源、具体内容），即使没有书面文件也可作为证词附件。
- [ ] **确认印章质疑的表述**：财务总监对确认余额请求函的印章应坚持“无印象、印章样式与日常使用不同、日期缺失”，并主动要求对方提供发送记录。

### 5.3 证据与法律论点准备
- [ ] **整理反方专家反驳论点**：预判被申请人可能引入反方中国法律专家论证“审计确认函结合会计记录可构成初步证据”。准备反驳论据，如引用最高人民法院（2019）民申字第XXX号等判例（可于庭前检索补充）。
- [ ] **准备内部调拨单质证策略**：若被申请人后续提交脱敏调拨单，应准备质疑其真实性（是否为事后补造）、法律性质（是否为物权转移凭证），并申请仲裁庭要求对方提供原始未脱敏版本以供对比。
- [ ] **汇总RAG引用**：将案例case007:0008和规则0014的原文打印备用，可在法庭上口头引用。

### 5.4 开庭当天行动
- [ ] **第一段盘问（清盘人）**：
  1. 要求提供内部调拨单编号、日期、发出公司。
  2. 追问调档函发送记录和实体名单。
  3. 在清盘人承认无法提供后，立即总结并申请不利推定。
- [ ] **第二段盘问（若对方律师对我方证人交叉盘问后）**：
  1. 要求对方提供确认余额请求函的发出记录。
  2. 质疑其印章真实性和日期缺失。
- [ ] **对我方证人直接询问时**：
  1. 主动引导证人展示“固定金额反证”逻辑。
  2. 对高风险问题（如诚信义务）确保证人使用完整回答口径。
- [ ] **程序应对**：若被申请人口头提出管辖权异议，立即引用贸仲规则和案例表明程序不应中止。
- [ ] **闭庭前**：整理需要仲裁庭记录的事项（如申请的命令、不利推定请求），确保书记员记录在案。
